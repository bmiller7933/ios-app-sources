# iOS app source

These folders are the Xcode source for each app. They are not installable apps.

On a Mac: Code, then Download ZIP. That saves one archive into your Downloads folder. Unzip it.

For each app folder: Xcode, New iOS App, SwiftUI, iOS 17, same name as the folder. Replace the generated Swift files with the ones in that folder. Read that folder's README.

Apps: ServeLog, NotaryBook, SOLCheck, CourtDayCA, CLEDue, LastDay, Rate9, BarOne, DaysLeft, ParkPin, SplitEven.
